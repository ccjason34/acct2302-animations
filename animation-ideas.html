How to use this planning catalog

  • Student path lives in the hub — use this page for instructor planning, not as the primary student landing page.
  • One hard idea, one moving model — each animation isolates a single concept students struggle with and makes it visual.
  • Predict before reveal — every animation pauses to ask a prediction (favorable or unfavorable? product or period?) before showing the answer.
  • Built for non-majors — relatable scenarios (taco truck, coffee shop, bakery) and the textbook's own companies (Sportswear Co., Custom Furniture Co.). Jargon is defined on first use.
  • Common-Trap callouts target the classic misconceptions (total vs. per-unit cost, sunk costs, favorable ≠ good).
  • Self-contained & offline — every file is a single HTML page with 3 Practice questions. No internet, logins, or installs needed; open in any browser.
  • Green badge = built & ready. Blue "Idea" = optional next animation to extend coverage.
