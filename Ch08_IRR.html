Common Trap

Check The Idea In Plain Language

Terms & formulas
Why This Matters

IRR gives the break-even return rate, but students still need to compare it with the required return.

Key Terms
  • IRR: Discount rate where NPV equals zero.
  • Required return: Minimum acceptable return.
  • Hurdle rate: Another name for required return.
  • NPV profile: How NPV changes as the discount rate changes.
Takeaway

IRR is a percentage hurdle test; NPV still shows dollars of value.

Show The Math

If IRR > required return, accept. If IRR < required return, reject. At IRR, NPV = $0.

Learning Objectives

  • Define IRR as the discount rate where NPV equals zero.
  • Compare IRR with the required return.
  • Explain why NPV remains the stronger decision rule when projects conflict.
