# Managerial Accounting Animations — ACCT 2302

Interactive teaching animations for **Principles of Managerial Accounting (ACCT 2302)**, covering Chapters 1–13. Each animation has a short worked model, a "predict-before-you-see-it" checkpoint, and a 3-question practice quiz. Everything runs in the browser — no install, no login, works offline once loaded.

## ▶️ Open the animations

### **https://ccjason34.github.io/acct2302-animations/**

Start at the hub and pick any chapter, or open a specific file directly.

## What's inside

- **30 chapter animations** (`Ch01_…` through `Ch13_…`) — cost flows, job costing, ABC, process costing, cost behavior, CVP/break-even, relevant costs, capital budgeting, budgets, variances, ROI/residual income, cash flows, and ratios.
- **`index.html`** — the student hub, with a suggested 15-week route.
- **`student-reference.html`** — key terms and formulas.
- Several animations include a **"Real-World Case"** box (Concorde, Forrest Gump, movie-theater popcorn, Apple, Ford, airlines, Amazon, Netflix) that links to an outside source for class discussion.

## For instructors

`animation-ideas.html` and `case-bank.html` are planning notes (concept catalog and a source-backed real-world case bank) — useful for lesson prep, not required for students.

## Reference

Aligned to Heisinger & Hoyle, *Fundamentals of Managerial Accounting*, v3.0 (FlatWorld). The animations are original teaching aids; real-world case boxes cite external news/reference articles as discussion prompts.
